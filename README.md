## WSTĘP

Proszę sklonować to repozytorium:

```bash
git clone https://github.com/MarcinCiura/SQL.git
```

Proszę zmienić katalog bieżący na katalog z klonem tego repozytorium:

```bash
cd SQL
```

Proszę skopiować plik `.sqliterc` do twojego katalogu domowego:

```bash
cp .sqliterc ~  # Unix
copy .sqliterc %USERPROFILE%  # Windows
```
